# Управление роботом через HTTP + QR-навигация

Этот проект состоит из двух частей:

1. **C++ HTTP-сервер** – получает команды (`forward`, `left`, `right`, `stop`) и управляет GPIO робота (AArch64/Linux).
2. **Python клиент** – через веб-камеру распознаёт QR-коды, вычисляет нужное направление и отправляет команды на сервер.

---

# Требования к ПК для сборки

Установите кросс-компилятор для ARM64 (aarch64):

```bash
sudo apt update
sudo apt install g++-aarch64-linux-gnu gcc-aarch64-linux-gnu cmake gi
```

Установите Python зависимости для клиента:

```bash
pip install opencv-python pyzbar numpy requests chardet
```

---

# Сборка C++ сервера (на ПК, для ARM64)

1. Cкопируйте файлы проекта в папку:

```
robot_gpio.h
robot_gpio.c
main.cpp
CMakeLists.txt
aarch64-toolchain.cmake
```

2. Создайте папку для сборки и выполните кросс-компиляцию:

```bash
mkdir build && cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE=../aarch64-toolchain.cmake
make
```

3. В папке `build` появится исполняемый файл `robot`.

4. Чтобы проверить, что исполняемый файл собран под ARM и статически нужно выполнить команду:

```bash
file ./robot
```

# Перенос исполняемого файла 

1. Подключитесь к роботу по ssh командой

```bash
ssh user@192.168.101

# дальше нужно ввести пароль и ура мы в роботе 
# и там дальше просто с небходимо создать папку для нашего файлика
mkdir project
# заходим в папку и туда переносим фацл робот 
cd project
```

2. Запуск файла `robot`

```bash
# сначала надо убедиться что мы в нужной папке и там есть наш файлик 
# команды:
pwd # покажет что мы в нашей папке 
ls # покажет robot

# ЗАПУСК РОБОТА 
./robot 
# или если будут проблеы с правами Permission denie
sudo ./robot
```

---

# Запуск Python клиента

1. Укажите в файле `client.py` IP-адрес вашего робота:

```bash
engine = FooEngine(server_url="http://192.168.1.100:8080")
```

2. Запустите клиент:

```bash
py client.py
```

# Возможные проблемы 

| Проблема                                | Решение                                                              |
| --------------------------------------- | -------------------------------------------------------------------- |
| `robot: command not found`              | Запускайте как `./robot`                                             |
| `Permission denied` при запуске сервера | Используйте `sudo` (нужен доступ к `/dev/gpiochip*`)                 |
| Не удаётся подключиться к серверу       | Проверьте IP робота (`ip a`), отключите firewall, используйте `ping` |
| Камера не открывается                   | Проверьте индекс камеры: `cv2.VideoCapture(0)` или `1`               |
| QR-коды не распознаются                 | Улучшите освещение, проверьте фокус камеры                           |
